AI Deal Health Score

Explainable CRM risk scoring based on engagement, stage velocity & sentiment

Why It Matters

Sales teams lose deals when engagement drops, stages stall, or sentiment turns negative. This module provides a clear AI Health Score, risk level, and recommended next steps — all inside Odoo CRM.

Key Features

  • Health score (0–100) based on engagement, stage velocity, and sentiment
  • Risk level: Healthy / Warning / At Risk
  • AI Suggested Next Action (Call, Email, Meeting, Todo)
  • Automatic activities created for at-risk deals
  • Chatter alert with reasons for risk
  • Kanban badges, score chips, and color indicators
  • Daily cron to re-score all active opportunities

How It Works

  1. Reads recent chatter, emails, and activities
  2. Calculates engagement + stage velocity signals
  3. Uses sentiment API (optional FastAPI service)
  4. Writes back score, risk reasons, and next action

Configuration

Set your sentiment API URL in Settings → AI Deal Health Score. Default: http://localhost:7860
